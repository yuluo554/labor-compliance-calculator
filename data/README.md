## 三、合成数据纪律

- **假身份白名单**：合成雇佣档案中劳动者一律虚构：姓名用明显虚构名（如"示例员工A"）、身份证号用**符合校验位算法但虚构**的号码、薪资为构造值；**禁止真实劳动者薪资或身份数据入库**。
- **假企业白名单**：合成用人单位用虚构名称 + 符合校验位算法的虚构统一社会信用代码（保留测试段，入库登记）。
- **植入真值**：合成档案由生成器产出时同时给出**期望计算口径与结果**（N/N+1/2N、封顶前后、年限取整、折算天数），真值随档案入库，引擎双路对账。
- **参数来源纪律**：参数包内每个社平工资/最低工资数值必须登记**发布机关 + 发布年度 + 口径（全口径/非私营） + 来源 URL**；来源不明不得入库；不同口径不得混算。
- **可复现**：生成器固定随机种子；产出物 sha256 留档。

## 四、法律与许可口径

- 法条条款库以"法律名 + 条号 + 要点"形式呈现（规避全文转载），原文以官方页面为准；
- data/knowledge/raw/ 快照为官方公文（著作权法第五条官方文件不适用版权保护）；
- 合成档案与真值库为本项目自制，MIT 许可随仓库发布。
