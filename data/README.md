> 规则（ai-tool-project-sprint 阶段 1）：每份数据登记来源与许可；规范条目挂出处 + status（`verified`/`pending`）；程序化自制带真值数据是核心资产（固定输入可复现）。`_private/` 目录不入仓。

## 四、合成数据纪律

- **假身份白名单**：合成雇佣档案中劳动者一律虚构：姓名用明显虚构名（「示例员工A/B/C/D」）、企业名虚构（「示例科技有限公司」）；**禁止真实劳动者薪资或身份数据入库**。
- **不构造身份证号**：M1 真值库不需要身份证号字段（计算不依赖身份号），故**不生成**——比"生成合规校验位再登记"更彻底地规避误用风险。
- **植入真值**：每条 = `input_facts`（可直接喂 `lcc calc`，CLI 自动取该字段）+ `expected`（主期望：口径/封顶前后/年限取整/折算天数/逐月差额）+ `also_expect`（隐含结论，由 `lcc/benchmark/cases.py` 的 `IMPLICATIONS` 谓词机械校验）。
- **参数来源纪律**：参数包内每个社平工资/最低工资数值登记**发布机关 + 发布年度 + 口径 + 来源 URL + 抓取日期**；来源不明不得入库；不同口径不得混算。
- **可复现**：生成器固定随机种子（自研 splitmix64，**禁 stdlib `random`**，守门测试断言）；产出物 sha256 留档。
- **不许改真值凑引擎**：真值语义单一实现源 `code/src/lcc/benchmark/cases.py`；引擎与真值不一致时改引擎 + 加测试（plan/05 §四.2）。

## 五、法律与许可口径

- 法条条款库以"法律名 + 条号 + 要点"形式呈现（规避全文转载），原文以官方页面为准；
- 各数据条目 `source.url` 直连官方原文（官方文件依法不适用版权保护）；
- 合成档案与真值库为本项目自制，MIT 许可随仓库发布。
