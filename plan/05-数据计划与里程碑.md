## 一、数据入库策略

### 1.1 三类数据的来源纪律

| 类别 | 内容 | 来源纪律 |
|---|---|---|
| 法定常数（全国统一） | 三倍倍数、12 年上限、150/200/300%、21.75 天、年休假分档、11 个月 | 逐条挂**法律名 + 条号 + 官方渠道 + 抓取日期**；条文数值以官方原文为准 |
| 地区参数（逐年逐地） | 社平工资、最低工资、法定节假日日历 | 逐条挂**发布机关 + 发布年度 + 口径 + URL + 抓取日期**；来源不明不得入库 |
| 条款库 | 法律名 + 条号 + 要点 | 要点摘述（规避全文转载）；挂官方渠道 |

### 1.2 status 生命周期

```
pending（初始化/未核对）
   ↓ 逐条核对官方原文（记录渠道 + 日期 + 摘录）
verified（已核对，可进入计算路径）
   ↓ 发现口径错误
修正值 + 重新核对（不得只改值不留痕）
```

**硬规则**：`pending` 条目不得进入计算路径（`gate.effective_ruleset()` 单点拒绝）。CLI 可 `--preview` 预览参数但不输出金额。

### 1.3 参数包生成策略

- `tools/gen_rulesets.py`：从 `data/regions/regions.json` × 年度区间生成 `data/rules/ruleset-<region>-<year>.json` 骨架，**全部 `status=pending`、`value="0.00"`、`source` 为空**；
- 骨架生成后由人工逐条核对填入（核对动作留痕在 `data/README.md` 台账）；
- **禁手改**：一旦某地区某年度核对完成，该文件进入冻结；后续修改走生成器 + 重新核对，配「再生成逐字节一致」守门测试；
- 确定性：自研 splitmix64 RNG（本项目骨架阶段不含随机成分，但生成器统一走确定性写盘纪律）；文本一律 `write_bytes` + `\n`。

### 1.4 合成雇佣档案生成器

`tools/gen_cases.py`（M1 实现）：

- **固定种子**（`splitmix64`，非 stdlib `random`）→ 两次生成逐字节一致；
- 产出 `data/truth/cases-<profile>.json`：每条 = `input_facts`（合成输入）+ `expected`（真值：口径、封顶前后、年限取整、折算天数、逐月差额）+ `also_expect`（同一输入隐含的其余结论，如"封顶生效"必然蕴含"12 年上限适用"）；
- **真值语义单一实现源**：`code/src/lcc/benchmark/cases.py` 定义对账语义，测试与基准共用，**不许改真值凑引擎**；
- 假身份：姓名用「示例员工A/B/C」、身份证号符合校验位算法但虚构、企业名虚构 + 虚构统一社会信用代码（测试段保留）；
- **覆盖矩阵**：口径判定 9 种情形 × 封顶（低于/恰好/高于三倍）× 年限（5/6/11/12/12.5 个月与年）× 工时制度 × 年休假分档 × 二倍工资起算上限。

## 二、基准设计（M4 落地，M0 起接口预留）

### 2.1 三类基准

| 基准 | 内容 | 目标 |
|---|---|---|
| B1 口径判定 | 解除情形 → N/N+1/2N 枚举（含易混边界） | 准确率 100% |
| B2 封顶与取整边界 | 三倍恰好等于/±0.01；年限 5/6/11/12/12.5/13；12 年上限 | 全通过 |
| B3 参数库自洽 | 跨地区/跨年度一致性；非法组合（不存在坐标、混用坐标、pending 条目）拦截 | 拦截率 100% |

### 2.2 边界自洽扫描（B2 深化）

- 从**规则表本身**推导全部有限边界（封顶基数由参数包算出，代码零字面量）；
- 取 `±0.01`（金额精度）邻域断言：封顶切换点、年限取整切换点、12 年上限切换点；
- **双向对账**：公式推导的边界端点 与 穷举扫描恢复的切换点，两条独立路径互验。

### 2.3 指标进 README

基准脚本 `tools/bench.py`，退出码 0 达标 / 1 未达标 / 2 用法错误；全量单次 < 1 秒；指标（通过数/总数、拦截率）写入 README 评测表。

## 四、既定口径清单（动了会打挂基准/测试的约定）

> 每次里程碑收尾写入 HANDOFF 速查；任何改动先对照本清单，改完重跑基准确认不回退。

1. **真值语义**：`expected` 主期望 + `also_expect` 隐含结论；对账按"全部非 pass 字段集"；语义单一实现源 `lcc/benchmark/cases.py`。
2. **不许改真值凑引擎**：发现口径错误改引擎 + 加测试。
3. **Decimal 口径**：JSON `parse_float=Decimal`；金额量化两位 `ROUND_HALF_UP`；天数按条款口径取整（取整方向为既定口径，变更需重核基准）。
4. **status 门控**：只有 `gate.effective_ruleset()` 产出可计算规则集；引擎不接受裸 dict。
5. **坐标精确匹配**：`load_ruleset` 不做模糊/回退；跨坐标必须报错。
6. **零政策字面量**：全部法定数值来自数据包；门禁扫描引擎/基准/前端源码（含 docstring/注释）。
7. **退出码**：0 成功 / 1 降级或计算非法 / 2 输入或坐标或门控错误；锁进 `test_cli_exit_codes.py`。
8. **测试全离线**：零网络、零 API、无 mock 外部服务需求。
9. **冻结产物纪律**：生成器产出禁手改；文本 `write_bytes`+`\n`；未来 zip 型产物统一 `ZIP_STORED`+`create_system=0`+固定时间戳。
10. **引擎层不得 import CLI/GUI**：AST 守门测试断言。

## 五、风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 地区社平工资/最低工资数值需逐地逐年核对，工作量大 | M1 进度 | 首期试点 ≥2 地区 × ≥2 年度，其余 `pending` 但**机制完备**；未核对即拒绝计算（不假装可用） |
| 代通知金、年休假取整方向等口径存在争议 | 结论正确性 | 挂"待核对"，以官方原文/司法解释核对后定稿；争议项在报告与文档显式标注 |
| 节假日日历逐年发布，滞后 | 计算可用性 | 未发布年度的规则包 `pending`，门控拒绝；文档说明 |
| 口径（全口径 vs 非私营）地区差异 | 跨地区误用 | 逐地区登记口径字段，禁止跨地区套用（坐标机制） |
| 桌面打包环境差异 | M5/M6 | 中立目录验证 + `env -i`；PyInstaller 版本按实测锁定 |
